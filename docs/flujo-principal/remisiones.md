# Remisiones

**Estado:** En desarrollo (menu visible, pantalla placeholder)
**Menu:** Operaciones -> Remisiones

## Para que sirve? (previsto)

Documentar la **salida de producto** terminado hacia el cliente despues de producir el pedido.

## URLs en el menu

- `/remisiones/nueva` — Nueva remision
- `/remisiones/informe` — Informe de remisiones

## Situacion actual

Las rutas del menu **aun no tienen formulario funcional** completo. Al ingresar puede ver mensaje de modulo en desarrollo.

**Hoy:** las condiciones de remision se registran en la **OT** (paso 2, condiciones de entrega).

## Cuando este disponible

1. Seleccionar pedido aprobado.
2. Registrar cantidades despachadas.
3. Generar documento de remision.
4. Consultar informe historico.
